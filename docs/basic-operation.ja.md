# 基本操作

## AIエージェントへの頼み方

このリポジトリをAIエージェントで開き、最初は次のどちらかを伝えます。

```text
このアプリを使えるようにしてください。
```

```text
このNijiUnit動画を参考に、自分の文章と素材で動画を作りたいです。
YouTube URL: https://youtu.be/xxxxxxxxxxx
```

AIエージェントは一度に一操作だけ案内し、利用者が完了したと返すまで次へ進みません。

## 自分の作品を始める

1. `input/`へ文章と、利用権を確認した画像・動画・音声を置く。
2. 横長`16:9`か縦長`9:16`かを決める。
3. AIエージェントと構成を相談する。
4. 最初の画像を確認する。
5. Excel絵コンテを確認し、修正または承認する。
6. 承認後だけ有料の動画生成へ進む。
7. 9コマ確認後、完成MP4を開く。

ExcelがなくてもHTMLで内容を確認できます。正式な承認記録はExcelで維持され、AIエージェントが操作を案内します。

## NijiUnit動画の作り方を読む

AIエージェントはYouTube URLの動画IDから、対応する公式制作ガイドをホームページで毎回直接読みます。PCへ古いガイドを保存して使い続けません。未登録動画なら停止して、その動画のガイドがまだ公開されていないことを説明します。

## 更新を確認する

新しい動画制作を始める前に、AIエージェントは最初に現在版を確認します。

```powershell
.\.venv\Scripts\python.exe run_storyboard.py check-update --language ja
```

これは確認だけで更新しません。更新候補があれば、AIエージェントが変更内容とローカル変更を説明し、確認を得てから進めます。
GitHubへ接続できない場合も勝手に更新せず、同梱された現在版で続けるかを利用者へ確認します。

## 困ったとき

- `scripts/doctor.py`: ローカル構成とAPI設定を診断。生成APIは呼ばない。
- `docs/troubleshooting.md`: 症状別の確認。
- `作業手順.md`: 省略できない正式な制作順。
