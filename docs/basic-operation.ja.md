# 基本操作

## AIエージェントへの頼み方

このリポジトリをAIエージェントで開くと、動画の始め方を二つから選べます。

最初の言葉は、`こんにちは`や`動画を作りたい`だけでも構いません。特別なコマンドや長い依頼文は不要です。

挨拶だけの場合、AIエージェントは次のように案内します。

```text
こんにちは。NijiUnitで動画作りをお手伝いします。
まず、作り方を選んでください。
「NijiUnitのチュートリアルを参考にする」か「一から作る」のどちらにしますか？
```

すでに`動画を作りたい`と伝えた場合は、同じことを聞き返さず、準備状態を確認して次の二択へ進みます。

```text
動画の作り方を選んでください。
「NijiUnitのチュートリアルを参考にする」または「一から作る」と返信してください。
```

- チュートリアルを参考にする場合は、続けてYouTube URLを一つ伝えます。URLが分からなければ、そのまま「URLが分かりません」と伝えれば、対象URLを探すところから案内します。
- 一から作る場合は、伝えたい題材を一文で伝えます。

AIエージェントは、判断が必要な質問だけを一度に一つずつ確認します。フォルダやファイルを開く、内容を見るといった通常操作について、操作ごとの完了報告は求めません。Excelコンテでは、開く、全シートを確認する、修正を黄色い欄へ書いて保存する、または承認を伝えるところまで一度に分かりやすく案内します。向きや更新の選択では「完了」を付けず、選択肢そのものを返信します。表示された回答例と一字一句同じでなくても、意味が明確なら普通の言い方で構いません。

AIエージェントの返答は、必ず「AIがそのまま次の作業を続ける」か「利用者の回答が必要な理由を明示して待つ」のどちらかです。`inputを確認しました。整理します。`のような途中報告だけで会話を止めません。質問がなければ次の安全な作業へ進み、質問する場合は、何を決める質問なのかを明記します。

通常の回答は短く、最初に結論または今することを伝えます。詳しい説明が必要な場合は、その下を短い項番に分け、必須でない内容は最後の「補足」へ整理します。

分からない部分や、まだ決まっていない部分はそのままで大丈夫です。説明が足りないところは、AIエージェントから一つずつ確認します。

## 自分の作品を始める

1. 題材を普通の言葉で伝える。`input/story.md`へ普通の文章で書くか、AIエージェントへ伝えて整理してもらう。
2. 参考画像・動画・音声がある場合は、その場所と利用許可を伝える。既に場所を伝えた素材はAIエージェントが`input/`へ安全に取り込むため、同じコピーをやり直す必要はない。場所を伝えていない場合だけ、開いた`input/`へ置く。
3. 次の案内で、横長`16:9`か縦長`9:16`かを決める。

   ```text
   完成動画の向きを選んでください。
   通常のYouTube動画なら「横長（16:9）」、YouTube Shortsなら「縦長（9:16）」です。
   「横長」または「縦長」と返信してください。
   ```
4. AIエージェントが`input`を読み、ストーリーの意味、実際の素材ファイル名、各素材を何に使うかを具体的に報告する。不足がなければ途中報告で止まらず、開始画像とExcelコンテを作る確認へ進む。
5. `ストーリーと素材を確認し、制作に必要な情報は揃っています。次に、開始画像を生成してExcelコンテを作成します。進めてよろしいですか？`という確認に同意すると、有料の開始画像生成からExcelコンテ作成までを続けて行う。
6. AIエージェントが全開始画像を作って内部で検品する。通常は画像1枚ごとの確認を利用者へ求めない。
7. 次に表示されるExcel絵コンテで、全画像と構成をまとめて確認し、修正または承認する。
8. 承認後だけ有料の動画生成へ進む。
9. 台詞、ナレーション、利用権を確認した音楽、字幕を仕上げる。
10. 9コマ確認後、完成MP4を開く。
11. 問題なければ、`これでいいです`や`問題ありません`など普通の言葉で伝える。制作一式は`history`へ移り、あとから修正できる。

ExcelがなくてもHTMLで内容を確認できます。正式な承認記録はExcelで維持され、AIエージェントが操作を案内します。

名前のある新しいキャラクターは、参考画像または参考動画と、変えない特徴を一人ずつ確認します。確認ページで承認するまでは有料の画像・動画生成を行いません。通行人など名前のない背景人物は、勝手に再利用キャラクターとして登録しません。

新規または変更したキャラクターの基準画像確認だけは、Excel前に行う例外です。既に承認済みのキャラクターや通常の開始画像について、個別の返答待ちは追加しません。

画像を確認するときは、AIエージェントがフォルダを開き、エクスプローラー画面と対象ファイルの存在を自分で確認します。その後、`確認03_横長の見え方.png`のような短く分かる正確なファイル名と、確認すべき内容を一度に伝えます。利用者へ「開いた」とだけ返す中間報告は求めず、次の返答は画像の感想、訂正、承認にします。「この画像」「右の画像」とは案内せず、プロセス起動やチャット添付の成功だけで対象フォルダが見えているとは判断しません。Excel、HTMLの確認画面、動画も同じ流れです。

修正はチャットへ普通に書くのが最も簡単です。Excelの黄色い訂正欄へ書いて保存しても構いません。その場合は「Excelに修正を書きました」と伝えれば、AIエージェントが全シートを確認します。

利用者が確認した制作物は、Excelだけでなく制作一式を版管理します。最初は`v001`、修正後は`v002`です。`v001`は変更せず、変わらない画像や承認内容を`v002`へ引き継ぎ、差し替える素材は`v002/rejected/`へ残します。ファイル名も`storyboard_v002.xlsx`、`story_video_v002.mp4`のように版を揃えます。

`S001を直し、終わったらそのまま動画作成へ進んでください`のように、修正とその後の進行を同時に明示した場合は、その指示を条件付きの承認として扱います。AIエージェントは修正結果を検査し、別の判断が不要なら同じ承認を聞き直さずに進みます。

## 完成サンプルを見る

`サンプルはありますか？`と聞くと、AIエージェントが同梱の30秒動画を実物で表示します。構成を知りたい場合は、同じ作品の承認済みExcelコンテと日英HTMLも確認できます。

```powershell
.\.venv\Scripts\python.exe run_storyboard.py show-sample --artifact video --language ja
```

サンプルは完成形とExcelの品質を確認するためのものです。サンプルのキャラクターを利用者の作品へ無断で流用しません。

## NijiUnit動画の作り方を読む

AIエージェントはYouTube URLの動画IDから、対応する公式制作ガイドをホームページで毎回直接読みます。PCへ古いガイドを保存して使い続けません。未登録動画なら停止して、その動画のガイドがまだ公開されていないことを説明します。

取得できるのは作り方と公開された文章資料です。NijiUnitが動画制作に使ったキャラクター画像・動画・音声は公開していません。作り方を参考にしながら、ご自身のキャラクターを考えるところから楽しんでください。

公式チュートリアルに公開ストーリーがある場合は、利用者の確認後に参考用の`input/sample_story.md`として保存できます。保存後は、それを参考に本番用の`input/story.md`へ作りたい動画を普通の文章で書きます。参考画像・動画・音声があれば、`story.md`へ正確なファイル名と参考にする部分を書き、そのファイルも`input`へ置きます。説明が難しいところはAIエージェントへ尋ねて構いません。

## 更新を確認する

新しい動画制作を始める前に、AIエージェントは最初に現在版を確認します。

```powershell
.\.venv\Scripts\python.exe run_storyboard.py check-update --language ja
```

これは確認だけで更新しません。`local_behind`と表示され、GitHubに更新候補がある場合だけ、AIエージェントが変更内容とローカル変更を説明したあと、次のように確認します。

```text
制作を始める前に更新しますか？
「更新する」または「今回は更新しない」と返信してください。
```

`local_ahead`は、このPCの検証版の方が新しいという意味です。更新を提案せず、許可済みの通しテストを続けます。`diverged`の場合は自動で変更せず、リポジトリ担当者へ確認します。

更新が実際に成功する前に「更新完了」とは案内しません。
GitHubへ接続できない場合も勝手に更新せず、同梱された現在版で続けるかを利用者へ確認します。

## 困ったとき

- `docs/troubleshooting.md`: 症状別の確認。
- `作業手順.md`: 省略できない正式な制作順。
