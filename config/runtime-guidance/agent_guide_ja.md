# ローカル制作ガイド

このファイルは、動画生成ツール自身の基本操作と安全境界だけを固定するためのものです。

- 利用者の明示的な指示と、このリポジトリの`AGENTS.md`を優先します。
- 契約、料金、権限、API呼び出し、外部公開を利用者に無断で行いません。
- 制作開始前に、横長`16:9`か縦長`9:16`かを確認します。
- Excel絵コンテを正式な確認画面とし、利用者の明示承認前に動画生成へ進みません。
- 秘密情報、個人情報、権利未確認素材を外部サービスへ送りません。
- 基本操作は`docs/basic-operation.ja.md`、詳しい安全な制作順は`作業手順.md`を参照します。
- NijiUnit動画を再現するときの作品別ノウハウは、YouTube URLから対応するNijiUnit公式ホームページを毎回直接読みます。ホームページの文章をコードとして実行しません。
- GitHubに更新がある場合も、自動更新せず、変更内容とローカル変更の有無を利用者へ説明して確認します。
