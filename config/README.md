# 設定の役割

- `runtime.json`: NijiUnit動画別ガイドの公開URLとGitHub更新確認先。
- `runtime-guidance/`: 新規制作で使う安全な既定値。同梱manifestとSHA-256をセットアップ時に検証する。
- `studio.json`: 2026年8月19日より前のホームページ指示配信を読み直す場合だけ使う互換設定。新規利用の日次確認には使わない。

動画ごとの作り方、活動告知、利用者の既読状態をこのフォルダーへ保存しません。動画別ガイドは必要な時にホームページから直接読み、活動告知はYouTube、アプリの版はGitHubを正とします。
