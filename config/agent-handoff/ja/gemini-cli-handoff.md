# Gemini CLIへの引き継ぎ

私はPC初心者です。公開リポジトリ `https://github.com/nijiunit/nijiunit-public-ai-agent-video-studio` を、このPCで使える状態にしてください。案内と説明は日本語でお願いします。

安全な読み取り、状態確認、文書確認、リポジトリ内の非破壊的な通常準備は、Gemini CLI自身が行ってください。私の操作や判断が必要なときだけ、目的を普段の言葉で短く説明し、質問または操作を一つだけ伝えて私の返答を待ってください。Gemini CLIが実行できるコマンドを私に入力させないでください。

最初にOSとGitを読み取り専用で確認してください。Windowsで今回使用できる場所は、`C:\Users\[user]\Documents\GeminiCLI\NijiUnit\nijiunit-public-ai-agent-video-studio` だけです。`[user]` は現在ログインしているWindowsユーザーの実際のフォルダ名へ置き換えてください。macOSでは、現在の利用者の `Documents/GeminiCLI/NijiUnit/nijiunit-public-ai-agent-video-studio` だけを使用してください。

会話、セッション、日付、タスク、実行用に作られた一時フォルダ、`workspace` フォルダ、添付されたフォルダ、別の作業で開いているリポジトリを保存先や対象にしてはいけません。指定場所の外から別のコピーを検索しないでください。

正確な対象場所にリポジトリがない場合だけ、そこへ新しく取得してください。公開リポジトリの取得にGitHubのIDやパスワードは不要です。認証を求められた場合は秘密情報を入力させず、取得元と原因を確認してください。

同名フォルダがある場合は、上書き、削除、名前変更、別名での再取得をしないでください。中身を読み取り専用で確認し、正しい正常なリポジトリならそのまま使用してください。破損、取得元の不一致、利用者の変更との衝突などが確認できた場合だけ、安全な案を一つ説明してください。

対象リポジトリが確定したら、Gemini CLI用のルート入口 `GEMINI.md` と、そこで指定された日本語の共通詳細ガイドを最初から最後まで読み、その指示を正として準備を続けてください。`AGENTS.md`をGemini CLIの入口として使いません。対象場所が確定するまでは、どの `.env` も読まないでください。確定後に使用できる `.env` は、正確な対象リポジトリ直下のものだけです。別フォルダや別リポジトリの `.env` を調べたり再利用したりしないでください。

既存設定と利用者の変更を保ち、準備や診断だけを目的として生成APIを呼ばないでください。APIキーが設定済みで変更がなければ初回設定画面を起動せず、設定をやり直すかも質問しないでください。未設定、交換・再設定を希望した場合、または保存済み設定の接続確認に失敗した場合だけ画面を使います。更新履歴の`diverged`など別の停止理由が残っている間は起動しないでください。APIキーはチャット、ターミナル、コマンド引数、URL、ログへ入力させず、必要な場合はローカル初回設定画面の秘密入力欄へ私自身が入力します。

初回設定画面が必要な場合は、リポジトリの起動スクリプトが実際に表示したローカルURLをチャットへ示し、そのURLをコピーして普段使っているブラウザのアドレス欄へ貼り付けて開くよう、次の内容を一度の返答で案内してください。

> 「NijiUnit 初回設定」を開く準備ができました。
>
> 次のURLをコピーし、普段お使いのブラウザのアドレス欄へ貼り付けて開いてください。
>
> `<ローカルURL>`
>
> 「NijiUnit 初回設定」が開くことを確認いただき、その画面の案内に沿ってGoogle生成AI APIの初回設定を進めてください。

この受け渡しではブラウザを操作したり、画面表示を代わりに確認したり、「開いた」というチャット返信を求めたりしないでください。正常な初回設定は画面内の案内へ引き継ぎ、Googleの実画面で判断が必要な場合だけ現在の公式情報で補助してください。起動できなかった場合だけ、開いたふりをせず、確認できた原因と次の一操作を案内してください。

システム全体へのインストール、権限追加、既存ファイルの削除や上書き、利用者変更の破棄、契約や課金、有料API呼び出し、Gitの取得元変更、pull、merge、commit、push、公開設定変更、確定範囲外への書き込みは、目的と影響を説明して私の確認を得てから行ってください。

コマンド成功と画面表示を区別してください。確認できないウィンドウ、フォルダ、ボタンを表示済みとして案内してはいけません。安全に続けられる間は自身で作業を続け、私の操作が必要になったときだけ、確認できた事実と次の一操作を伝えてください。

それでは、読み取り専用の確認から始め、安全に進められるところまで続けてください。
