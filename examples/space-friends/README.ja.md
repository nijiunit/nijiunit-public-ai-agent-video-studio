# 完成サンプル「星のむこうの虹」

初心者が、完成動画と正式なExcelコンテを実物で確認するための公開サンプルです。

- `demo.mp4`: 30秒の完成動画
- `storyboard_approved.xlsx`: 全10ショットを承認済みにした正式Excelコンテ
- `storyboard_approved_review.ja.html`: Excelがない場合の日本語確認ページ
- `storyboard_approved_review.en.html`: English review page
- `sample_story.md`: この公開サンプルで使った参考用の物語と固定事項

このサンプルは完成形と確認方法を理解するためのものです。同じ入力でも生成結果が同一になる保証はありません。ご自身の動画では、`input`に置いた文章と利用権を確認した素材を使い、キャラクターとExcelコンテを改めて確認します。

サンプルのキャラクターを利用者の作品へ自動流用しません。NijiUnit公式チュートリアルを参考にする場合も、ご自身のキャラクターを考えるところから案内します。
