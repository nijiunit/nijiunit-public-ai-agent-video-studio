# Finished sample: “The Rainbow Beyond the Stars”

This public sample lets a beginner inspect a finished video and the official Excel storyboard used for human review.

- `demo.mp4`: finished 30-second video
- `storyboard_approved.xlsx`: approved 10-shot Excel storyboard
- `storyboard_approved_review.ja.html`: Japanese offline review page
- `storyboard_approved_review.en.html`: English offline review page
- `sample_story.md`: reference story and fixed details used for this public sample

The sample demonstrates the finished form and review method. Generative output is nondeterministic, so identical input does not guarantee an identical result. A user's production must use its own `input` story, rights-cleared media, reviewed characters, and approved workbook.

The sample characters are not silently reused in a user's work. A NijiUnit tutorial still guides the user through creating their own characters.
